# ML-004 — Bar-only JEPA and self-supervised market-state learning

**Status:** Open for implementation. **Reference:** https://github.com/fin-ai-lab/tfwm

## Question

Can an encoder trained to predict future **latent representations** from past OHLCV context capture state changes useful to a downstream trade-outcome head, without exposing test ranges during self-supervised pretraining?

## Plan

1. Reproduce a small JEPA-like architecture (causal context encoder, target encoder or stop-gradient teacher, small predictor) using purely artificial bars. Upstream TFWM equity encoders are ideas, **not** assumed usable NQ checkpoints.
2. Separate contrastive/reconstruction/latent objectives and choose a single target representation. Keep the design small enough for a consumer GPU.
3. Permit future-target sequences **inside the training fold only**. At inference, supply *only* the context known at decision close.
4. Implement synthetic leakage tests and training loss convergence checks; compare the representation to equal-capacity supervised encoder and simple bar features when real data become available.
5. Keep checkpoint weights local; record the architecture and seed in a submission note.

## Exit

A more complex pretrained representation is unjustified if it fails out-of-time baseline improvement after costs. No real data = architectural feasibility only.
