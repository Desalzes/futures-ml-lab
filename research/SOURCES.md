# Model families and primary repositories

Last manually assembled 2026-11-20. Original GitHub repo presence was checked on 2026-11-20. **Check exact branch, revision, release, weight availability, data provenance and licensing again before starting an experiment.** Links here do not imply that the model is trained on or profitable for NQ/MNQ.

| Family | Upstream repository | Why investigate |
|---|---|---|
| Futures Foundation Model | https://github.com/johnamcruz/Futures-Foundation-Model | Pretrained futures-specific bar encoder, with a 5-minute feature construction pathway |
| Kronos | https://github.com/shiyu-coder/Kronos | Financial candlestick-token architecture and pretrained checkpoints |
| Financial World Modeling / TFWM | https://github.com/fin-ai-lab/tfwm | Comparative self-supervised representation objectives, including JEPA-style learning |
| Mamba / Mamba-2 | https://github.com/state-spaces/mamba | Sequence modeling alternative; train on bars only, do not use order-book-specific implementations |
| PatchTST | https://github.com/yuqinie98/PatchTST | Patch-based time-series Transformer baseline |
| Chronos | https://github.com/amazon-science/chronos-forecasting | Probabilistic forecasting reference with available pretrained family |
| FinCast | https://github.com/vincent05r/FinCast-fts | Financial mixture-of-experts time-series reference |
| LightGBM | https://github.com/microsoft/LightGBM | Essential low-complexity comparator |

No repository here has been independently established to generate positive **after-cost NQ/MNQ trade returns**. Public forecast and classification metrics alone do not establish executable alpha.
